# Derby Paulista
Extraia o ZIP e abra index.html no navegador. Para editar, abra a pasta Derby no VS Code.
O jogo funciona offline, com dois jogadores no mesmo aparelho. O Palmeiras começa cada partida.
O placar vale enquanto a página do jogo estiver aberta.

As páginas História e Dicas estão em pages/. O visual está em css/mystyle.css e a lógica do jogo em js/myscript.js.
O carrossel usa Bootstrap local e três cartazes em img/. Os escudos dos clubes foram obtidos no acervo de imagens da ESPN.
